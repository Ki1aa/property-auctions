# Исследование полей ГИС Торги (land-filter)

Цель: на **реальных** ответах OpenData list + notice detail зафиксировать правило «земельный лот» и заполнить `INGEST_LAND_FILTER_BIDD_TYPE_CODES` (и при необходимости дополнительные поля), **не** опираясь на `catCode=7` / `categoryCode=7` до проверки.

## Стратифицированные выборки

Для каждой выборки сохранить сырой JSON (или выдержку) и таблицу значений полей:

1. Земельные участки, **регион 72** (Тюменская область).
2. Земельные участки, **другие** регионы.
3. **Транспорт** / машины.
4. **Помещения**.
5. **Оборудование**.
6. Извещения с **несколькими** `notice.lots[]`.

## Поля для фиксации

Минимум: `catCode`, `category`, `biddType` / `biddTypeCode`, `resourceTypeUse`, `title` / `name`, `permittedUse`, `landCategory` (и вложенности из detail JSON).

## Результат

После заполнения таблиц — перенести выводы в `.env` (`INGEST_LAND_FILTER_BIDD_TYPE_CODES=...`). До этого в dev можно `INGEST_LAND_FILTER_RELAXED=true` (только отладка).
